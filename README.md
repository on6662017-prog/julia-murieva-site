# Сайт Юлии Мурьевой — интерьер и Васту

Одностраничный сайт (один файл `index.html`, фото встроены).

Черновик закрыт от поисковиков (`noindex`). Перед запуском на своём домене удалите строку `<meta name="robots" ...>` в `index.html`.

Не хватает данных от Юлии: собственные курсы, даты и цены мастер-классов, портфолио, отзывы, год диплома, проверка описаний секторов Васту.
