# Сайт Юлии Мурьевой — интерьер и Васту

Одностраничный сайт: `index.html` + фото в `img/` (WebP), кадры проекта в `img/p/` (`NN.webp` — полный размер для галереи, `NN-s.webp` — превью), видео в `media/`.
Анимации: GSAP 3.15 + Lenis 1.3 (плавная прокрутка), отключаются при «уменьшении движения» и если библиотеки не загрузились.

Предыдущая версия сохранена в `v1.html`.

Черновик закрыт от поисковиков (`noindex`). Перед запуском на своём домене удалите строку `<meta name="robots" ...>` в `index.html`.

Цена «3 000 ₽/м²» для «Васту + дизайн интерьера» взята из варианта v2 — подтвердить у Юлии.

Не хватает данных от Юлии: второй и следующие проекты для портфолио, отзывы, даты и цены мастер-классов, год диплома, проверка описаний секторов Васту.
